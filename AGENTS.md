# Who Gets What

UK benefits-by-area data and visualisation app, published as Who Gets What,
an independent project with no organisation behind it
([ADR 0011](docs/adr/0011-call-the-site-who-gets-what.md)). TanStack Start
(React) built with Vite and deployed to Cloudflare Workers. README targets
users; this file is for agents and maintainers working on the repo.

## Commands

```bash
mise install                          # node 24, pnpm 11, Python 3.14, uv, hk and hook binaries
pnpm install --frozen-lockfile
pnpm run dev --host 127.0.0.1 --strictPort   # dev server on 127.0.0.1:3000, runs in workerd
pnpm run typecheck                    # TypeScript 7 by explicit path
pnpm run lint                         # oxlint, type-aware; warnings fail
pnpm run format:check                 # oxfmt; `pnpm run format` writes
pnpm run test                         # vitest
pnpm run build                        # prerender ~2,040 pages, share cards, sitemap, robots.txt; needs public/data
pnpm run size                         # JS and data budgets; needs a build and public/data; --data <folder> for a compiled release
pnpm run prerender:check              # after a build: every page and share card written, asset count, banned and style-list words
pnpm exec playwright install chromium # once: the browser for Playwright (no lifecycle script)
pnpm run test:e2e                     # after a build: Playwright specs on 127.0.0.1:4320
pnpm run perf:explore                 # after a build: morph frame times, 4x CPU throttle (software GPU)
pnpm exec wrangler deploy --dry-run   # needs a build first; uploads nothing
hk check --all                        # every hook gate over the whole repository
pnpm run data:ingest                  # fetch sources into pipeline/build; uncached Stat-Xplore queries need STAT_XPLORE_API_KEY
pnpm run data:compile                 # canonical Parquet and pipeline/build/site/{release}
pnpm run data:test                    # pytest; tests over pipeline output skip until a compile
pnpm run data:pull -- --local         # copy the compiled release into public/data, check it and remove other releases
pnpm run data:release                 # pack the newest compile and write data.lock.json; `--publish` runs gh release create
pnpm run data:pull                    # download the release data.lock.json pins into public/data; removes other releases
pnpm run audio:build                  # film narration, cues and score into public/audio; uncached requests need ELEVENLABS_API_KEY
pnpm run audio:build -- --only narration   # after a beat's words change; --offline uses cached takes only
```

`/styleguide` (noindex) shows every token, ramp, type style and component.
Check visual changes there in light, dark and 390px width.

Deploy with `pnpm run deploy`, never bare `pnpm deploy`: that is pnpm's own
workspace command, not the package script.

## Layout

- `src/routes/` holds file routes. `src/routeTree.gen.ts` is generated by the
  TanStack Router plugin on dev and build (or `pnpm run generate-routes`). It
  is committed, excluded from lint and format, and never edited by hand.
- `worker-configuration.d.ts` is generated by `pnpm run cf-typegen` from
  `wrangler.jsonc`. Regenerate it after a binding change.
- The build writes `dist/server/wrangler.json`, the effective deployment
  configuration.
- Tests are `*.test.ts` files beside their source under `src/` and `scripts/`;
  Playwright specs are in `e2e/`.
- Data pages (dossiers, comparisons, rankings, embeds, methods, data, the area
  index) render to static markup in server functions (`src/server/pages.ts`,
  `src/pages/`) and hydrate only the shell
  ([ADR 0007](docs/adr/0007-render-data-pages-to-static-markup.md)). Their
  controls are `data-*` attributes wired by `src/lib/enhance.ts`; no React
  event handler in `src/pages/` ever runs.
- `src/content/` builds page views from contract data: figures in every price
  basis, templated sentences, ranks and comparisons. Sentences go through
  `src/content/sentences.ts` so tests can check them for banned words.
  Pages and the explorer share one module per job: `src/lib/format.ts` for
  numbers and periods, `src/content/labels.ts` for names,
  `src/content/sentences.ts` for copy and `src/domain/rank.ts` for ranks.
- `src/domain/` is the shared kernel: branded types, the data contract parsers
  and the URL-state codec. It imports nothing from routes or components.
- `pipeline/` is the Python data pipeline (uv project `wgw_pipeline`, tests in
  `pipeline/tests`). Everything it writes goes to the ignored `pipeline/build/`.
  `scripts/data-pull.ts` fills the ignored `public/data/`.
- `src/styles.css` holds every design token once (`light-dark()` pairs on
  `:root`); `src/design/` reads them back so tests check contrast. The
  Tailwind default palette is removed, so only token colours exist.
- `src/components/ui/` is vendored shadcn/ui (`components.json`), adapted to
  the repo's lint and types. Add more with
  `pnpm dlx shadcn@latest add <name>`, then run lint and typecheck.
- `src/lib/preferences.ts` owns theme and reduced-motion rules and the inline
  head script that applies them before first paint.
- `src/data/source.ts` is the one port every page reads release data
  through: `fetch` in the browser, the Worker's `ASSETS` binding on the
  server (registered by `src/server.ts`), and `src/data/testing/file-source.ts`
  over `public/data` in tests.
- `src/explore/` is the `/explore` route's code and `src/viz/` its pure
  layouts and colours; `src/viz/engine/` is the lazily loaded deck.gl
  island. Nothing outside `src/viz/engine/` imports deck.gl, luma.gl or the
  engine, so they stay out of the server build and the main chunk.
- `src/film/` is the home route's film (`/film` redirects to `/`):
  `script.json` holds every word the film says, the controller drives the
  shared engine from scroll, the player (`player.ts`, a reducer in
  `playback.ts`) scrolls it under the narration's clock, and
  `grains/` bakes grain scenes in a worker. `public/audio/` is generated by
  `pnpm run audio:build` (`scripts/audio/`) and committed; a Vitest test
  fails when a beat in `script.json` has no recording of the same words.
- `contract/neutrality/banned-words.json` is the one ADR 0004 banned-word
  list. `src/domain/neutrality.ts` reads it, and Vitest runs it over every
  route and the compiled catalogue. `pipeline/tests/test_compile_honesty.py`
  reads the same file for pipeline copy, with the same whole-word rule.
- `contract/neutrality/style-words.json` lists metaphors and filler that no
  reader sees or hears ("grains", "skyline"). Vitest runs it over the
  film script, the catalogue, every area view, the data pages, the shell
  routes and the home page; `prerender:check` runs it over every built page.
  People's names are data, not copy: mark each one `translate="no"` and the
  page checks skip it, so a candidate called Heap passes.
- `contract/schema/` is generated from `src/domain` by `pnpm run test -u` and
  is never edited by hand. A contract change updates
  the schema, `contract/fixtures/` and the pipeline in the same change.

## Conventions

- The hk pre-commit hook (`hk.pkl`) gates formatting, lint, typecheck, tests,
  gitleaks and the build-script decision check. Do not bypass it.
- Every dependency with a lifecycle script needs an `allowBuilds` entry in
  `pnpm-workspace.yaml`; the hook fails without one. Denial (`false`) is the
  default. Granting `true` is the maintainer's decision.
- A lint suppression names its rule and gives a reason after `--`; an unused
  suppression fails lint.
- Prose uses British English.

## Gotchas

- `prepare` sets `core.hooksPath`, but a global pnpm `ignoreScripts` skips it.
  On a fresh clone run `git config --local core.hooksPath .hk-hooks` once.
- Without `--strictPort`, `pnpm run dev` moves to another port when 3000 is
  busy, so a smoke test against 3000 can hit another app.
- The Cloudflare Vite plugin copies the root `.env` into
  `dist/server/.dev.vars`. Never put secrets there; the Stat-Xplore key goes in
  the environment or `pipeline/.env`.
- The gitleaks hook scans staged changes only (`gitleaks git --pre-commit
  --staged`), so `hk check --all` does not scan the tree. Run
  `gitleaks git --no-banner .` to scan the whole history.
- `vite preview` keeps the old asset hashes after a rebuild and returns 500s.
  Restart it after each build.
- `pnpm run build` reads `public/data/{release}` to list pages, so run
  `pnpm run data:pull` first. `.env.production` sets `VITE_SITE_ORIGIN`, the
  origin of canonical links, share cards, embed code, `robots.txt` and the
  sitemap; an environment variable of the same name overrides it. Dev and
  Vitest do not read it, so they use the `.example` placeholder.
- The area page and main chunk sit within about 1 kB and 5 kB of their
  120 kB JS budgets (`pnpm run size`; see the architecture budgets). Anything
  the shell, a dossier or a route's `validateSearch`, `head` or `loaderDeps`
  imports counts, since those stay in the route tree; load page-specific
  code with `import()`.
- Playwright's headless shell renders WebGL with SwiftShader, a software GPU,
  so canvas frame rates there are far below a real device. Measure frame
  rates through playwright-cli, whose browser uses the real GPU.
- A full-page screenshot taller than about 16,000 px (a ranking, a dossier)
  fails and can crash the browser's GPU process, which turns WebGL off for
  that session; the explorer then shows its static SVG. Reopen the session
  before checking the canvas.
- deck.gl's event manager (mjolnir.js) sets `tabindex="0"` and no outline
  on its canvas. Both engines set it back to -1 in the `Deck`'s `onLoad`,
  since the canvas is `aria-hidden`.
- TanStack Router patches `history.pushState` and scrolls to the element a
  pushed hash names. An in-page link that scrolls with its own code, like
  a film chapter link, must not push the hash.
- Changing a beat's words in `src/film/script.json` re-records that beat and
  the beats stitched to it (`pnpm run audio:build -- --only narration`),
  which spends ElevenLabs credits. Check the new takes with speech-to-text
  as [docs/film/audio.md](docs/film/audio.md) describes before committing.
- The `typos` hook reads some ElevenLabs voice ids as misspellings. Check a
  new voice id with `typos` before casting it.
- The audio cache (`node_modules/.cache/audio`) belongs to one checkout. A
  worktree that records new takes must copy its cache back to the main
  checkout before it is removed, or the next `audio:build` re-records them.
- `src/domain/compiled-data.test.ts` reads the newest release in
  `pipeline/build/site`. After a contract change, a stale local compile fails
  it; run `pnpm run data:compile` first.
